# Simple Task Management Application

A beginner-friendly task management web app.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark status: To do, In progress, Done
- Set priority and due date
- Search and filter tasks
- Saves tasks in browser localStorage
- Responsive layout for desktop and mobile

## Run

```bash
npm start
```

Open:

```text
http://localhost:3000
```

## Files

```text
server.js
package.json
README.md
public/index.html
public/styles.css
public/app.js
```

This simplified version does not use login, database, or external packages. It is easier to understand and modify.
